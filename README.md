🌱 Fruits To-Do - Full-Stack MERN Application
Track your favorite fruits with style! A colorful todo list featuring emoji integration and real-time updates

✨ Features

🍎 Add fruits with automatic emoji matching

🌈 Gradient background with animated UI elements

🔄 Real-time sync between frontend and backend

📱 Responsive design for all screen sizes

🛡️ Secure MongoDB Atlas database integration

🛠️ Tech Stack

Frontend: React.js + Axios + CSS-in-JS

Backend: Node.js/Express + Mongoose

Database: MongoDB Atlas (Cloud)

Deployment: Render (Backend) + Vercel (Frontend)
